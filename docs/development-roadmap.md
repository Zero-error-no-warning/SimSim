# 開発指針（2026-10-07）

社内の静的HTTP/HTTPS配信、計算後の記録再生、ノードによる設定、必要な操作だけを開く画面構成を維持する。

## 実装済みの機能

- 「地形格子数」を領域サイズと独立して変更し、補間後の地形を細かく編集できる。現在／設定後の格子間隔を表示する。ロゴ横の画面版を更新番号から自動生成する。

- タスク一覧・ユニット一覧・3D表示・ユニット編集を4ペインに分離。名前・現在状態はユニット一覧に集約し、担当・選択・ホバーを地図と連動。幅調整・タスク一覧の折りたたみと表示設定の保存に対応。
- 「計算履歴」で全期間のユニット別状態遷移、探知、通信、到着などを表示。クリックで再生時刻へ移動する。履歴は計算完了・記録読込時に一度だけWorkerから渡し、時刻を戻しても保持する。
- 最大12点の状態到達計測。各点のany/all/count・期限を独立して評価。段階間の成立時刻の差、起点成立後の到達率、順序逆転件数を表示する。
- 計測点別に未達試行を選び、同じシード・試行番号・抽出値で記録を作り再生する。
- 「段階別計測・通信履歴」サンプル。中継通信の成功確率を変え、報告開始・中継開始・UAV移動開始・到着を確認する。

- 感度分析：現在の設定を基準に一項目ずつ変更し、対応試行の率・時間の差と近似区間、候補の順位、対象強調、基準・変更の再生、保存・再読込を追加。[集計仕様](sensitivity-analysis.md)。

- 運用案の比較：配置・経路・報告間隔・挙動を最大8案で保存。共通条件と乱数で対応差を集計し、通常画面で案の切替・保存・更新、案ごとの編集保持とTXT復元に対応。分析画面で保存済み案を比較し、対応再生・結果保存を行う。[仕様](operation-plans.md)。成功条件のトグルを廃止し分析では常に使用。

## 残る項目と実装順序

| 順序 | 項目 | 次の実装単位 |
| --- | --- | --- |
| 1 | 情報の不確かさ | 観測位置と真位置を分離。観測誤差、観測時刻からの経過、失探、識別確度を受信情報に保存する。真位置を判断に流用しない。 |
| 2 | 長時間運用の量 | 燃料・電池・弾数・搭載量を共通の資源残量として定義。時間・距離・行動に応じた消費、補給、閾値での帰投、交代を追加する。 |
| 3 | 地球の丸み・通信媒体 | 見通しに地球曲率を追加。媒体別に速度・使用領域・遮蔽条件を定義し、固定処理遅延と距離による伝搬時間を分ける。 |
| 4 | 高度方向の軌跡 | 現在の3D経路に時間指定の高度・深度プロファイルを追加。上昇・降下率、弾道モデルと途中の地形制約を検証する。 |
| 5 | 探知の指向性 | 移動方位とセンサー方位を分離。視野角・俯仰角・走査周期を探知判定と3D表示に反映する。 |
| 横断 | ノードエディタの自由度 | 資源閾値・情報の古さなど、追加した値を条件式から参照。複数条件、変数、繰返し、割込み優先順位を順次拡張する。 |

## 計測と比較の共通ルール

到達率の分母は、当該比較条件の完了済み全試行。対象数0は未達として含める。所要時間の中央値は起点・終点が成立し、終点が起点以降の試行だけを対象にする。起点成立後の到達率の分母は起点成立試行で、順序逆転は分子に含めない。複数担当の条件が成立した時刻どうしの差であり、同じ個体の移動時間とは限らない。

現行の追加計測点は**状態への初回到達のみ**。地理的な計測線・領域、追尾継続時間、個体別の段階間時間、複数項目の組合せ効果の自動分析は未実装。探知・通信などは、そのイベントで入る状態を計測点にする。瞬時に退出する報告状態もイベント履歴から計測する。

計測点がある分析はシナリオの終了時刻まで実行する。主ミッションの期限以降も別の計測点を記録するためで、主ミッションの成功条件・期限は変更しない。集計・記録形式には追加計測結果を保存する。既存の計測点を持たないversion 3シナリオ・記録・version 5分析結果は引き続き読み込める。

将来のIMEE連携は、ユニット・タスク・状態IDと時刻付きイベントを基にタイムラインへ変換する。確率分布を渡す際は、未達試行を分母から取り除かない。連携自体は今回の実装には含めない。

# SimSim 0.2 検証記録

2026-10-02。架空の地形・ユニットでのソフトウェア動作検証。実際の装備能力や探知性能を検証したものではない。

## 計算モデル

`node tests/engine.test.mjs`、`node tests/random.test.mjs`。

- 一定速度、一度だけ／往復／周回、時刻の前後移動、地形への投影と停止。
- 同じシード・試行番号での再現。評価順・評価頻度・ユニット配列順の影響を受けないこと。
- 試行番号／シードを変えたときの経路変化。
- 出発点・目的地の固定、ノイズの最大値、上下ずれの適用領域。
- 出発遅れ、速度ばらつき、実経路長に沿った移動。
- 群の共通ずれ、ランダム配置で個数を増減した際の既存メンバーの維持。
- ノイズで範囲外へ出る経路を失敗として残すこと。
- 上限・重複ID・不正入力の拒否、定義の保存・再読込。
- 1000個の群と1007個のサンプルの計算。

参考測定: Node.js v24の実行環境で、1000個のノイズ付き経路の構築約239ms、1時間を10秒間隔で評価する36万個分の位置計算約101ms（1回の実行）。描画・探知・通信を含まない。ハードウェアの異なる社内ブラウザの速度を保証する値ではない。

## ブラウザ

Playwright＋headless Chromium、ソフトウェアWebGL、1500×980／390×844。`/SimSim/`配下の静的HTTP配信。CSPで外部スクリプト・通信を禁止し、同梱データは`.jsn`をtext/plainとして配信。

- 1007個の初期表示とmodule Workerからの移動結果。
- インスタンス記号の地図クリック選択、生成メンバーの読み取り専用表示。
- 群の追加・編集・削除、1000→100の変更、Undo／Redo。
- 合計2000個を超える設定でエラーを表示し、直前の定義を保持。
- 試行変更と元の試行への復帰、同じ時刻での位置一致。
- 高さ表示倍率を変えても計算位置が変わらないこと。
- `.jsn`保存には単体7個＋群定義を格納し、生成済み1000個を格納しないこと。再読込。
- 既存の単体編集、地図での経由点追加、HTML文字列の安全な表示、無効ファイルの拒否。
- 横方向のページあふれなし、狭い画面の群編集ダイアログ、Console例外・外部アクセスなし。

参考測定: 上記1007個のサンプルは描画呼び出し25回、50フレームの間隔中央値約33ms（静止画面、ソフトウェアWebGL、1回の実行）。実GPU・社内ブラウザでの性能評価は別途必要。

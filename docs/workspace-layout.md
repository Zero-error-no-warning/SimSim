# 盤面を中心にした画面構成

画面版29（2026-10-09）。計算モデル・シナリオ形式は変更しない。

## 常設するもの

盤面と計算・再生・時刻移動を中心にする。通常表示では対象一覧を一つ開き、ユニット／タスクをタブで切り替える。対象を選んでも詳細ペインを自動で開かず、「詳細」で必要時に開く。表示・編集の追加操作は各メニューにまとめる。

集約表示に入ると左右の一覧・詳細を閉じる。集約の内訳表は「結果」に置き、盤面の高さに影響させない。集約中でも一覧・詳細を手動で開ける。個体表示へ戻す際は、それ以前の開閉・タブを復元する。

## 操作の置き場所

| 利用目的 | 入口 | 内容 |
|---|---|---|
| 対象を探す | 対象一覧 | ユニット／タスクの選択・追加 |
| 選択対象を調べる | 詳細 | 概要・現在状態・保有情報、設定編集 |
| 盤面を読む | 盤面／表示 | 集約、視点、資源、経路などの表示 |
| 定義を変更する | 編集／対象の右クリック | 配置、地形、シナリオ設定、運用案の管理 |
| 試行を準備する | 計算設定 | 終了時刻、乱数、刻み、記録間隔 |
| 時刻を動かす | 再生バー／再生操作 | 計算・再生・シーク・刻み送り・速度 |
| 実行を調べる | 結果 | 現在時刻の状態、記録情報、集約表、履歴、経路検査、保存 |
| 複数試行を比較する | 分析 | 既存の計測・感度・運用案・定石の分析 |

設定・結果・運用案の管理は閉じられる別画面で開く。短い計算状態は再生バーに残し、詳細は結果へ置く。通常の操作通知は盤面上で一時表示し、警告は次の通知まで保持する。通知で盤面の高さを変えない。

## 機能を追加するときの規則

追加項目は上表の利用目的へ割り当てる。新しい入力欄や表を、初期画面の盤面の上下・左右へ常設しない。定義の入力は設定契約へ、表示切替は表示メニューへ、実行の詳細は結果へ登録する。常設する操作を増やす場合は、盤面を読んでいる間にも必要である理由と、既存操作との重複を確認する。

設定編集中は中央に編集領域を確保する既存の構成を使う。表示設定・ペイン幅はブラウザの好みとして保存し、シナリオを変更しない。集約の一時配置で通常の好みを上書きしない。

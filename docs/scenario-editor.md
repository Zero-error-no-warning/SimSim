# 地図でのシナリオ編集（0.6.0）

地図で配置・経路を操作し、右の設定欄で属性を調整する。地形自体の編集、複数選択、行動ノード編集は今後の機能。

## 配置と視点

「配置編集」は初期状態で有効。再生・60秒送り・時刻スライダー・分析履歴からの時刻移動で解除する。再び有効にすると一時停止し、時刻0へ戻す。

| 操作 | 動作 |
| --- | --- |
| 記号または左の一覧をクリック | 選択し、設定・計画経路を表示 |
| 配置編集中に記号を左ドラッグ | 初期位置と経路全体を水平移動 |
| 群のメンバーを左ドラッグ | 群のひな型と全メンバーを水平移動 |
| 選択中の番号付き経由点をドラッグ | その点だけを変更 |
| 何もない場所を左ドラッグ | 3Dで視点回転。真上表示では回転しない |
| 右ドラッグ／ホイール | 視点移動／拡大縮小 |
| F／「選択へ」 | 選択対象を画面中央へ |
| 「全体」 | 地形全体が見える視点へ戻す |

地上では地形面、水上では海面、水中・空中では既存の深度・高度の平面を使う。水中・空中のドラッグで高度は変えず、設定欄から調整する。群の配置幅・分散方式・個数・乱数は維持する。周回の出発割合も維持するため、群のメンバーの現在位置とひな型の経路基準点は一致するとは限らない。

ドラッグ中は仮表示、放すと一回の編集として確定。Esc・ポインター操作の中断・地形の範囲外や選択点の地形制約違反で取り消す。経路全体や群の全メンバーの通行可能性を保証するものではなく、確定後の地形制約は既存の計算・設定欄で確認する。Undoは25段階。

## 追加・複製・周回

地図の右クリックか上部の「操作 ▾」で同じメニューを開く。タッチ操作では「操作」を使う。メニューでは上下矢印、Home/End、Enter、Escも利用できる。

- 新しいユニット: 領域を選び、地図上の位置をクリックして確定。左の領域選択＋「追加」でも同じ。Escなら追加しない。
- 複製: 対象を選び「複製して配置」またはCtrl/Cmd+D。属性・経路・行動をコピーし、地図クリックで配置する。群も複製可能。通信の受信先は元の参照を維持し、単体の自分宛てだけ新IDへ変更する。
- 経由点: 「経由点を追加」を選び、地図を順にクリック。Escで終了。群ではひな型へ追加する。
- 周回: 「中心と半径で周回経路を作成」→中心→円周の順にクリック。半径を仮表示する。既存経路を32頂点の閉じた多角形へ置換し、出発割合を0%にする。円周のクリック位置が経路の基準点。群の周回分散方式は維持する。半径50～50000m、全頂点が地形の領域条件を満たす必要がある。取り消しはEsc、作成後はUndo。

経路表示をオフにすると経由点ハンドルも隠す。番号0は経路基準の初期位置。記号と重なると隠し、記号のドラッグを優先する。経由点1以降をクリックしてDeleteでその点だけ削除できる。初期位置0だけを変更するときは右の「地図で初期位置を指定」を使う。

## 削除・新規・保存

Deleteまたは削除メニューで単体／群を削除する。群のメンバーを選んだ状態では群全体が対象。選択した経由点がある場合、Deleteはその点だけを削除する。

削除した対象への情報送信ルール、比較・抽出変数、成功条件の対象参照を整理する。最後の対象・対応ユニットを削除すると成功条件を解除する。Undoで関連設定ごと戻せる。

「新規」は現在の地形を維持し、ユニット・群・成功条件を空にして分析条件を初期化する。別の地形を使うときはシナリオファイルを開く。編集した配置・経路・属性は上部の「.jsnを保存」で保存する。

Ctrl/Cmd+ZでUndo、Ctrl/Cmd+Shift+ZまたはCtrl/Cmd+YでRedo。Spaceは再生／一時停止。入力欄・選択欄・ダイアログ内ではこれらのグローバルショートカットを実行しない。
